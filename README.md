# مُجيب — مساعد الأسئلة الدينية والتاريخ الإسلامي

تطبيق ويب عربي (RTL) يجيب عن الأسئلة الدينية وأسئلة التاريخ الإسلامي بإجابات موثقة بالمصادر،
ويرفض التخمين: «لا إجابة بلا دليل».

## المعمارية

1. **قاعدة معرفية موثقة** (`knowledge.js`): عشرات الأسئلة والأجوبة مع مصادرها
   (صحيح البخاري ومسلم، كتب السيرة والتاريخ) — إجابات فورية بشارة «✓ إجابة موثوقة».
2. **طبقة ذكاء اصطناعي** (Gemini 2.0 Flash) لأي سؤال خارج القاعدة، بتوجيه صارم:
   مصادر إجبارية لكل معلومة، و«لا أعلم» بدل الاختراع، وإحالة الفتاوى لأهل العلم.
3. **وسيط آمن** (`functions/ask.js`): دالة Netlify serverless تُخفي مفتاح Gemini،
   فيستخدم الزوار الموقع بمفتاح المالك دون رؤيته.

## التشغيل

انظر `DEPLOY.md` (بالعربية) لخطوات النشر على Netlify.

## الأمان

- لا يُرفع المفتاح الحقيقي إلى GitHub أبدًا (انظر `.gitignore`).
- المفتاح يُضبط كمتغير بيئة `GEMINI_KEY` في لوحة Netlify فقط.
